# AGENTS.md

This project follows the DeployDock agent instructions in `AGENTS_DeployDock.md`.

Important working rules:

- Build one milestone at a time.
- Stop after each milestone and wait for user approval.
- Do not introduce out-of-scope MVP features.
- Treat SSH keys, credentials, command execution, and ownership checks as security-sensitive.
- Keep the code clear enough for a junior-to-mid backend developer to study.
